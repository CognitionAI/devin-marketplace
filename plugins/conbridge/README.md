# ConBridge

By Arven Soft. [Homepage](https://conbridge.app) · [Tool documentation](https://conbridge.app/docs/mcp/tools) · [Privacy policy](https://conbridge.app/legal/privacy) · [Support](mailto:support@conbridge.app)

Read the known vulnerabilities ConBridge found on the computers, servers and CMS sites you own, confirm one with a read-only check, and fix it on the one target you select. Whether an action runs at once or waits for the owner's approval follows the owner's rule for that target. ConBridge never changes a system by itself.

The remote endpoint is `https://mcp.conbridge.app/mcp`, using Streamable HTTP and OAuth 2.1 with PKCE and dynamic client registration. No API key, header or client ID is required. ConBridge is listed in the official MCP Registry as `app.conbridge/conbridge`.
