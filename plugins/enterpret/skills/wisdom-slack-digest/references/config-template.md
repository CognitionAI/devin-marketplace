# Wisdom Slack Digest — Configuration Template

<!--
  This is the TEMPLATE for digest configuration.

-->

## Digest title

```yaml
digest_title: "Weekly Customer Feedback Digest"
```

## Delivery

<!--
  Where the digest is delivered. Detected automatically during setup
  based on available MCP connectors.

  Supported types: slack, email, cowork
  - slack: requires channel_id
  - email: requires address
  - cowork: no destination needed (displays in chat)
-->

```yaml
delivery:
  type: "slack"
  destination: "REPLACE_WITH_CHANNEL_ID"
  channel_name: "#channel-name"
```

## Topics

<!--
  Each topic tracks a set of keywords/themes in the Wisdom KG.
  The setup wizard builds these from your stated goals.

  Tips:
  - 2-4 focused topics works best
  - Keywords should be at theme-level granularity, not L1 categories
  - Include case variants or use toLower() matching
-->

```yaml
topics:
  - name: "Topic 1"
    keywords:
      - "keyword1"
      - "Keyword1"
    description: "What this topic tracks and why it matters"

  - name: "Topic 2"
    keywords:
      - "keyword2"
    description: "What this topic tracks and why it matters"
```
