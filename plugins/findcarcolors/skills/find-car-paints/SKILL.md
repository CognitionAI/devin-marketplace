---
name: find-car-paints
description: Use when looking up automotive paint names, paint codes, or manufacturer paint catalogs.
---

Use search_car_paints to search by manufacturer, paint name, or code.
Use get_paint_details to read a specific record and its available sources.
Use list_manufacturer_paints to browse a manufacturer's catalog.

Report the paint code and available sources from the returned records. Say when a code is missing or the match is ambiguous. Catalog coverage is partial and screen swatches are approximate.
